# PixelEngine 主教练战术库 — dust_2
# 用途：追加进固定 system prompt（利于 cache_prompt）。不要塞进每次会变的 digest。
# 约束：只使用引擎已有 intent 枚举；区域名须来自地图 site 层。
# 引擎不执行烟雾线，道具描述仅作「时机/意图」参考，slots.area 才落到站位。

【地图区域别名】
A侧: A_Site Long Outside_Long Long_Door Pit Side_Pit A_Car Plate Ramp Cat Short Short_Stairs Blue
B侧: B_Site Tunnel Upper Lower Outside_Tunnel Door Car_B Plate_B Big_Box Fence Dog Jump_Box Titanic
中路: Mid Top_Mid Xbox Double_Doors Suicide
出生: T_Spawn CT_Spawn

【总规则】
1) 优先级: 炸弹状态 > 经济 > 减员/人数 > 接触信息 > 笔记
2) 已下包: CT只用 retake_a/retake_b 且 target=包点侧; T只用 stack_a/stack_b(或default但target=包点侧)
3) 穷局(!下包): 优先 save; T禁止 rush/split/fake
4) 连续两回合同 intent+同 target 失败 → 必须换点或改 fake/split/default
5) 开局约前20s偏 default 换信息; 中段再 execute; 时间不足才 rush
6) 不要每回合重复同一侧速推; reason≤20字只写当下事实

────────────────────────────────
T 满钱 / 强起
────────────────────────────────
default | target="" | tempo=normal | ttl=18~25
  站位意图: 2人 Long/Outside_Long; 1人 Top_Mid; 1人 Cat/Short; 1人 Tunnel/Upper
  目的: 前30s换信息(Long谁在、Mid门、B是否前压)，再决定点
  何时: 开局默认; 敌情未知; 上回合刚换边后的首回合

rush_a | target=A | tempo=fast | ttl=10~14
  路径: 全员经 Long → A_Site (可留1人 Cat 晚到夹击)
  何时: CT未站稳; 时间不足; Long已换到人且对方人少; 开局想打乱CT
  勿用: 刚在A连续失败; 经济穷; 已知A叠人

rush_b | target=B | tempo=fast | ttl=10~14
  路径: 全员 Tunnel/Upper → B_Site，必须赶在回防前结束
  何时: CT Mid/A过早暴露; 时间轴靠前的速攻; 反制CT激进Tunnel
  勿用: 已过回合中段还没进点(回防已到)

split_a | target=A | tempo=fast | ttl=12~18
  路径: 3 Long + 2 Cat/Short 同时进A (先有 Mid/Cat 接触更好)
  何时: 默认后确认A只有1~2人; CT把人堆在B; Long已控制
  勿用: Mid完全丢失且Cat被卡死(变两次单独冲锋)

split_b | target=B | tempo=fast | ttl=12~18
  路径: Mid压 Door/Xbox + Tunnel 同步进B
  何时: 已拿Mid信息; CT过早回A; 反制双B锚点单独守洞
  勿用: Mid门被死守且无人能换下

fake | target=B或A(真打点) | tempo=normal→fast | ttl=14~20
  意图: 2人在佯攻侧制造接触/噪音，主力转另一点
  何时: CT习惯早回防; 上回合同点被叠防; 有时间完成转点
  成功条件: 看到回防迹象再转; 否则改打佯攻侧(改 rush/split 同侧)
  勿用: 时间不足; 穷局; 无人确认回防却空想转点

────────────────────────────────
T 穷 / 强起失败后
────────────────────────────────
save | target="" | tempo=slow | ttl=18~25
  站位: 靠近 T_Spawn / 远离混战，避免白给枪
  何时: 开局平均经济穷; 或规则已判定保枪

default(穷局弱默认) | 仅当不允许 save 时
  小心换枪/捡枪，不主动开大战

────────────────────────────────
CT 满钱
────────────────────────────────
default | target="" | tempo=normal | ttl=18~25
  站位意图: 2A(Long/Pit + Short/Cat) + 1 Mid + 2B(Window/Door侧 + Site锚)
  目的: 先听前10~15s再决定叠哪边; 避免A/B同时丢控制
  何时: 开局默认; 敌情未知

stack_a | target=A | tempo=normal或slow | ttl=12~20
  意图: 3~4人偏A (Pit/Long/Cat/Site)，留1人听B或Mid
  何时: T连续打A; 经济局防速A; 笔记/近局显示A高频
  勿用: 刚在A被拆穿且B无人; 已下包在B

stack_b | target=B | tempo=normal或slow | ttl=12~20
  意图: 3~4人偏B (Tunnel口/Site/Door)，留人看A
  何时: T连续B洞; eco防五人洞; 中路烟后怀疑B
  勿用: 已确认大部队Long

retake_a | target=A | tempo=fast | ttl=12~18
  仅已下包@A: 从 CT_Spawn + Short/Cat 两路汇合，禁止单人滴入
  站位: Entry走 Short/Cat 或 Cross; Anchor清 Site

retake_b | target=B | tempo=fast | ttl=12~18
  仅已下包@B: Door/Window 与 Tunnel 方向协同，禁止单人进点

局势 → 剧本(预备回答)
────────────────────────────────
敌早期 Tunnel 前压 → CT: 暂守B交叉开火，Mid协助; T: 可改 rush_a 打空档
敌早期 Long 对枪丢失 → T: 不要硬A，转 default/fake 或 rush_b; CT: 可轻度压Long信息
已控制 Long 且 Cat 有人 → T: split_a 或 rush_a
已控制 Mid/Door → T: split_b 优先于盲 rush_b
CT早回防明显 → T: fake 后转另一点

人数我方少1 → tempo偏 slow，default/stack 等枪，避免 rush
时间不足(事件TimeLow) → T: rush 有接触的一侧; CT: default收位点，勿盲目 peek
拆包中 → CT: retake 对应点掩护; T: stack 对应点回防包点
下包后残局 → 禁止再选另一点的 rush/stack
