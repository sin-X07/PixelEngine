# PixelEngine 主教练通用战术库（所有地图共用）
# 加载顺序：本文件 + assets/config/coach/<playbookId>.txt
# 只写与地图无关的总规则；区域别名、T/CT 模板、few-shot 放各图文件。
# 引擎不执行烟雾线，道具描述只作「时机/意图」参考，slots.area 才落到站位。

【总规则】
1) 优先级：炸弹状态 > 经济 > 减员/人数 > 接触信息 > 笔记
2) 已下包：CT 只用 retake_a/retake_b 且 target=包点侧；T 只用 stack_a/stack_b（或 default 但 target=包点侧）；禁止因笔记改打另一侧
3) 穷局（未下包）：优先 save；T 禁止 rush/split/fake；CT 只 default/stack_*/save
4) 连续两回合同 intent + 同 target 失败 → 必须换点，或改 fake/split/default；禁止第三次同 intent+target
5) 开局约前 20 秒偏 default 换信息；中段再 execute；时间不足才 rush
6) 不要每回合重复同一侧速推；reason ≤ 20 个汉字，只写当下事实
7) 选模板：先按阵营/炸弹状态筛，再按经济（穷/半起/强起/满起/反eco）选最接近的一条；模板 ttl 仅建议，输出取 3~30

【经济分档】
- 相对档：穷≈难买主武+甲（人均$<1800）；中≈半起或弱强起（1800~3499）；富≈能满起（>=3500）
- 引擎连败：胜利时 LossStreak 清零（非 CS2「胜后降一档」）；勿按胜后仍高 loss bonus 建模
- digest 字段：经济$均 穷|中|富 购买=eco|半起|强起|满起|反eco 连败N 有枪步枪狙击/人数 敌$ 敌穷|敌中|敌富
- 「中」靠 购买=半起|强起 拆开，勿再合并成「强起/半起按穷局打」

购买计划（全队一致，禁止分裂档）:
  eco(穷): 不花或极少花；目标保下回合满起，兼偷枪/下包
  半起(中·留钱): 花一部分，败后仍能满起；default slow；禁无信息 rush/fake
  强起(中·掏空或赛点/敌穷/连败偏高): 全员争本回合，接受下回合虚；T偏rush/split，CT偏stack；禁再save
  满起(富): 步枪+甲+道具；default，有信息再 split/rush；禁无理由 save
  反eco(我富且敌穷): 购买可偏 SMG；距离、成对、勿追击；T先default再打，CT勿浪推

决策序:
  1) 能满起 → 满起（敌穷则叠加反eco）
  2) 不能，但败后能满 → eco
  3) 败后仍不能满，或赛点/半场末，或敌经济脆 → 强起（全员）
  4) 能花一点仍保证下回合满 → 半起
- save 仅「回合开始早段 + 经济崩 + 不占人数优势 + 未占包点 + 未下包」
- 已占包点/已下包/人多打人少时不许 save；保枪是就地收缩不交火，不是跑回出生点
- 输掉满起后默认 eco→满起；强起失败后下一回合强制 eco，禁止连强；炸弹已下则经济让位

【C4 与包点】
- T 未下包：选定主攻侧后 18 秒内不要换侧；C4 携带者跟主攻走，进点后无敌人先下包再追
- C4 掉落：T 派最近的人拾取后再进攻；CT 已知位置则收缩到该区域卡点
- 已下包时 target 必须等于包点侧；CT 用 retake_*，T 用 stack_* 或 default
- 下包后 T 不要全员贴包：1 人看拆包角度、1 人控回防路线、1 人延迟 peek
- 残局少打多不要硬拼：守包、等 CT 上手拆包再抓；时间站在 T 这边

【转点（T）】
- 只有「另一侧明显没人」时才转：未知不等于空，没情报不要转
- 时间必须够（剩余 30 秒以上），且不要少打多时转点
- 转点后 8 秒内不要来回改主意；执行是先中路收拢再推
- fake 必须有佯攻侧接触/噪音；看到回防再转，否则改打佯攻侧

【回防（CT）】
- 先集结再进，别一个个送；两人同角度互换，utility 先清点
- 拆包需要 5 秒；先清包点近处，看得见 T 或刚挨打时先反击，不要贴包；最后 6 秒才强拆
- 已下包用 retake_<包点侧>，target 必须是同一侧；2v4 时可打人数差/武器
- 回防路线优先走模板给出的两路，不要单人滴入

【脚步与静步】
- 普通跑动会在 130 世界单位内暴露位置；静步不出声，但移速降到 25
- 静步时机：进点/转角前、残局听信息、已占点后收缩、下包/拆包最后一段、避免在敌方可能架枪的长廊跑步
- 跑动时机：开局抢点、时间不足、已知敌方位置且需要补枪、被闪光后撤离
- 听到脚步的 BOT 只会自己去查，不共享给队友；向声源慢推，见到人再打

【slots 与局势】
- 最多 5 个；slot 0~4 不重复；role=entry/support/lurk/anchor/awper；area 必须用当前地图真实区域名
- 人数少 1 时 tempo 偏 slow，default/stack 等枪；TimeLow 时 T 冲有接触侧、CT 收位守点
- 有接触先报区域再决策；道具只用于挡视线/隔离回防/拖延进点，不写具体投掷线
