# 美术素材与 UI 设计说明

本目录保存在联网检索时下载的**可商用 CC0 素材副本**，供后续替换/参考使用。
游戏运行不依赖这些文件（它们不在 `assets/` 里），移动或删除都不影响构建。

---

## 一、素材清单

| 文件 | 来源 | 许可 | 内容 |
|---|---|---|---|
| `kenney_ui-pack.zip` | [Kenney · UI Pack](https://kenney.nl/assets/ui-pack) | **CC0 1.0** | 430 个 UI 元件（按钮/滑条/复选框/箭头/星星），蓝红绿灰四色系 |
| `kenney_top-down-shooter.zip` | [Kenney · Top-down Shooter](https://kenney.nl/assets/top-down-shooter) | **CC0 1.0** | 580 个俯视角资源（地砖/墙体/箱子/枪械/人物四方向行走） |
| `extracted/` | 上面两个 zip 的解压副本 | CC0 | 便于直接浏览 PNG（可删除，不影响仓库） |

> CC0 意味着可商用、可修改、无需署名（Kenney 希望但不强制署名）。

### 两份素材的实际观感

- **UI Pack**：扁平圆角 + 纯色高光，偏"休闲手游"。**不建议整套替换**当前 UI
  —— 颜色（亮蓝/亮红）与 CS 战术主题、像素地图不搭。
- **Top-down Shooter**：橙 (#E07B3A)、草绿 (#4CAF50)、青灰 (#7FB8B8)、
  深灰 (#3A3F45) 的配色**很适合作为战术游戏参考**。人物是 4 方向行走、
  带枪械变体，可作未来替换 `cs2d/sprites/*_player.png` 的备选。

## 二、本次 UI 改造（代码侧）

### 1. 分辨率无关

| 机制 | 位置 |
|---|---|
| 内部画布：高度锚定 1080，宽度按窗口比例 | `Engine::ResizeLogicalViewport` |
| 全局 UI 缩放 `g_uiScale = min(宽/1920, 高/1080)` | `Graphics/UiScale.hpp` |
| 布局尺寸统一 `UI(x)` 宏 | 全 `GameUI.cpp` / `CS2DOverlay.cpp` |
| 字体与控件样式整体缩放 | `ImGuiUI::SetUiScale`（`FontGlobalScale` + `StyleAllSizes`） |

结果：16:9 → 缩放 1.00；16:10 → 0.90；4:3 → 0.75；21:9 → 1.00（左右留空）。
**任何比例都不会裁切**，因为设计基准 1920×1080 在缩放后总能完整放进逻辑画布。

### 2. 各界面适配情况

| 界面 | 处理 |
|---|---|
| 主菜单 | 内容块整体垂直居中（实测 1080 高：块高 428.8，上下留白各 325.6） |
| 地图选择 | 标题/卡片/按钮/提示全部 `UI()`，卡片尺寸随缩放 |
| 设置 | 滚动区高度 = 视口 − 标题 − 页脚；返回按钮固定底部（实测底边 1065.6 < 1080） |
| 暂停 / 退出确认 | 改为内容块垂直居中 |
| 买枪菜单 | 宽高随 UI 缩放，高度 = min(470, 视口−48)，内容超出自动滚动 |
| 记分板 | 同上，带滚动条 |
| HUD 血条/护甲 | 位置与尺寸全部缩放，文字与条对齐 |
| 装备栏（右下） | SDL 面板与图标乘 `g_uiScale`，文字改用同一套公式（原来写死 y=549） |
| 击杀播报 | 右上角 + 半透明背板，行距与宽度缩放 |
| 目标状态（C4/人质） | 顶部药丸背板 + 居中文字 |
| 雷达 | 尺寸/边距随缩放；点位半径随 mapZoom；玩家与友军圆点、可见敌人红点 |
| 准星 / 命中标记 | 线宽、长度、间隙、标记大小乘 `g_uiScale` |

### 3. 视觉统一

- 新增 `Graphics/Palette.hpp`：深海军蓝底 + 沙漠金强调色，语义色分离
  （危险红 / 友军绿 / 信息蓝）
- 菜单、暂停、退出确认统一加**渐变背景 + 顶部金线 + 底部暗角**
- 主菜单标题加短金线；按钮悬停时左侧亮起金色竖条
- 按钮配色改为暗金属底 + 悬停偏金（不再是通用灰蓝）
- 顶部计分条 / 击杀播报 / 目标状态都加半透明背板，让 HUD 从"漂浮文字"
  变成有层次的界面

## 三、设计评审（当前状态）

### 已经像"产品"的部分

1. **统一的视觉语言**：金 + 深蓝贯穿菜单、HUD、按钮悬停，不像临时 Demo
2. **层级清楚**：标题 34 / 副标题 20 / 分组 15–16 / 提示 14–15
3. **反馈完整**：悬停变色 + 金色竖条、按钮按下变暗、闪光/受伤全屏反馈、
   命中 X 标记、击杀播报背板
4. **HUD 有结构**：顶部分数面板、右上播报面板、左上雷达、左下血甲、右下武器

### 仍然欠缺的（按优先级）

| 优先级 | 问题 | 建议 |
|---|---|---|
| **P0** | 人物/武器仍是占位方块 | 用 `extracted/kenney_top-down-shooter` 的四方向人物替换，或按 `ASSET_SPEC.md` 画 64×64 朝上武器 |
| **P0** | 地图美术风格不统一（`ancient_ruins.jpg` 与 `dust_2.png` 画风差异大） | 统一色温/描边风格；地图选择卡片已有预览图，统一后观感提升最大 |
| **P1** | 买枪菜单信息密度高、缺图标 | 接入 `kenney_ui-pack` 的图标或自绘武器剪影，左右布局改为"分组卡片" |
| **P1** | 击杀播报是纯文字 | 加"击杀者 → 武器图标 → 被击杀者"三段式，配队伍色 |
| **P2** | 主菜单缺背景画面 | 用一张地图俯视截图 + 暗化 + 渐变遮罩作背景，比纯渐变更抓眼 |
| **P2** | 字体层级只有 5 档 | 增加一个 40+ 的超大标题字重，用于结算画面 |
| **P3** | 结算/回合横幅样式单薄 | 加淡入淡出 + 队伍色底条 |

### 配色结论

- 主色 **#12202B（深海军蓝）**、强调色 **#EDAE4D（沙漠金）**、
  危险 **#E65752**、友军 **#59DB82**、信息 **#6BB8F2**
- 与两张地图（沙色遗迹 / 沙漠）都能呼应，不抢画面
- Kenney UI Pack 的亮蓝/亮红**不建议**直接用于主界面，会破坏战术感

## 四、如何验证

```bash
# 任意分辨率与渲染缩放下跑一遍
EngineApp.exe --mapselect          # 看地图选择卡片
EngineApp.exe --autostart --mode=2 # 看 HUD / 雷达 / 武器栏
```

设置里切换 `分辨率`（只改窗口）与 `渲染缩放`（改内部画布），
UI 应当保持同一相对大小与居中位置。
