# 主菜单小鸡、局内购买双层轮盘与赛前武器配装实施计划

本文供 UI、玩法和测试实现使用。玩家在大厅决定这场比赛各阵营能买哪些枪，进局后用两次选择完成购买；点击庭院里的小鸡也用相同手势换装。三个入口共用武器定义或轮盘控件，各自保留独立的存档与操作结果。

## 一、原作依据与本项目取舍

| 资料 | 可复用的机制 | 在 PixelEngine 中的落点 |
|---|---|---|
| Valve 的 CS:GO 2020-02-24 更新，及原版界面记录 | 打开购买轮盘时指针居中，可购买状态直接显示在轮上。原版一级为手枪、重型、冲锋枪、步枪、装备、投掷物，进入类别后选具体物品。 | 两个入口都用整圆扇区，第一次确认进类别，第二次确认选条目。局内购买键开盘时指针回到圆心。[Valve 更新说明](https://blog.counter-strike.net/ko/2020/02/29106/) · [布拉格查理大学论文中的 CS:GO 实机购买界面](https://dspace.cuni.cz/bitstream/handle/20.500.11956/85140/BPTX_2015_2_11410_0_439637_0_184929.pdf?isAllowed=y&sequence=1) |
| Valve 的 CS2 2023-06-06 更新 | 每个阵营独立配置 1 个起始手枪位、4 个手枪位、5 个中型武器位、5 个步枪位。可拖放同类枪械，CT 可以同时选两种 M4。局内界面在这一版改为网格，并支持退还当回合购买且未使用的物品。 | 大厅采用单屏槽位编辑器，局内采用 CS:GO 的轮盘。护甲、工具与投掷物在各自购买类别里提供。沿用项目现有退款凭据与规则。[Valve 单篇更新](https://store.steampowered.com/news/app/730/view/3702568031467145905) · [Valve《Goodbye Wheel》及完整更新正文](https://store.steampowered.com/news/posts/?appids=730&enddate=1688085097&feed=steam_community_announcements) |

**狙击枪单列为购买入口，和普通步枪共用 5 个赛前槽位。** 例如 CT 同时选 FAMAS、M4A4、M4A1-S、SSG 08、AWP，局内“步枪”显示前三把，“狙击枪”显示后两把。把 AWP 换成 AUG 后，两页分别显示四把和一把。这样玩家能直接找到狙击枪，也看得见为它放弃了哪个选择。小鸡的类别、以下扇区顺序和确认后的停留位置均为项目设计。

## 二、两个轮盘怎样操作

| 操作 | 小鸡定制 | 局内购买 |
|---|---|---|
| 打开 | 点中现有 3D 小鸡，沿用聚焦动画；左侧看模型，右侧出现一级轮盘。进入时忽略刚才点鸡的松键。 | 在允许购买时按当前购买绑定（默认 B），切到绝对鼠标，在对应窗口坐标居中到盘心。保留已有自动开盘入口。 |
| 悬停 | 扇区提亮，中心显示类别或选项全名，当前已应用项带勾。 | 一级显示类别与可见条目数，二级显示图标、价格。中心显示全名、可购状态或具体原因，余额和购买剩余时间固定在盘外。 |
| 确认 | 一级选类别，二级选值。点击具体值立即应用，停在当前类别，便于连续对比。 | 一级选类别，二级买一件。成功后回一级并显示成交物品和余额，方便接着买别类。失败停在原页并提示原因；时窗关闭则直接退盘。 |
| 返回与退款 | 二级点中心或按 Esc 回一级，一级同操作退出聚焦。 | 二级点中心或按 Esc 回一级，一级同操作收盘。任一层再次按购买绑定都直接收盘。二级商品上右键退一件，显示实际退款反馈，留在该页。 |
| 键盘 | 数字 1 至 N 对应当前层可见的顺时针扇区；方向键轮选，Enter 确认。 | 使用同一导航。占用的数字键事件在菜单内消费，关闭时释放捕获，避免同时切枪、开火或打开暂停。 |

首扇区中心位于十二点方向，余项顺时针排列。一级、二级在同一圆心切换。布局、数字提示和命中共用同一组起止角。建议初值为内半径等于外半径的 30%，中心独立处理返回，扇区间隙和外圈以外均可松开取消。按下与释放须在同一个有效扇区，每次实体按键只触发一次动作，切层后必须重新按下；鼠标可以停在原方向继续点。对局关盘时恢复原有相对瞄准，丢弃切换造成的第一帧相对位移。若购买绑定恰为导航键，当前绑定的开关动作优先并消费事件。

视觉复用现有烟色半透底、细颗粒和香槟色选中边。纹理随扇形裁切，悬停用亮边，已选用勾，可退用退款标记，禁用仍可悬停查看原因。绘制和命中使用同一局部坐标系，轮盘随可用短边缩放。小鸡页给模型留出左半屏，购买页在较宽屏幕用旁区显示详情，较窄屏幕收进盘心与下方提示。图标缺失时仍能凭名称、价格和编号完成选择。[现有控件材质](../PixelEngine/Graphics/ControlMaterial.hpp)

### 小鸡的两层内容

| 一级扇区 | 二级扇区，按项目已有选项顺序 |
|---|---|
| 1 配饰 | 无、小帽子、墨镜 |
| 2 姿势 | 散步、待机、张望、休息 |
| 3 颜色 | 原色、白羽、棕羽、黑羽、蓝羽、绿羽、红羽 |

一级 3 扇区，二级按内容画 3、4 或 7 个扇区，七种颜色一页可见。颜色扇区同时使用色样和名称。“无”是有效配饰值。显示顺序通过类别标识映射到现有索引（颜色 0、姿势 1、配饰 2）。确认时传回真实类别和值，继续走现有选中、3D 更新和保存回调。悬停只预览文字或色样；切换小鸡后重新从一级打开，并读取那只小鸡的勾选状态。[选项目录与模型接口](../PixelEngine/Graphics/Menu3D.cpp) · [聚焦界面](../PixelEngine/Graphics/GameUI.cpp) · [应用和保存回调](../PixelEngine/Engine.cpp)

### 局内的两层内容

| 一级扇区 | 二级来源与固定顺序 |
|---|---|
| 1 手枪 | 当前阵营起始手枪在首位，再列 4 个手枪槽。 |
| 2 中型武器 | 按 5 个中型槽的次序列出所选冲锋枪、霰弹枪、机枪。一级副标题写明这三类。 |
| 3 步枪 | 取 5 个步枪槽中类型为 Rifle 的条目，保留相对顺序。 |
| 4 狙击枪 | 取同一组中类型为 Sniper 的条目，保留相对顺序。 |
| 5 装备 | 护甲、护甲与头盔、Zeus x27、拆包钳；拆包钳按现行 CT 资格展示。Zeus 在库存占副武器位，在商店归装备。 |
| 6 投掷物 | 高爆雷、闪光弹、烟雾弹、阵营燃烧类、诱饵弹。T 对应燃烧瓶，CT 对应燃烧弹。 |

每次打开取当前阵营的对局配装。未入选枪械从列表剔除；余额不足、已有、达到携带上限的条目仍在原位并显示原因。若类别为空，保留一级位置并标明“未配装”。购买资格与退款资格分别读取，即使武器显示“已装备”，有有效凭据时仍可右键退款。保留刀的出生发放及 C4 的模式发放。价格、图标、阵营和武器类型均取自武器定义，装备走现有购买请求。[武器目录](../PixelEngine/CS2D/Weapons/WeaponDef.hpp) · [购买与退款](../PixelEngine/CS2D/CS2DGame.cpp)

## 三、大厅“武器配装”页

入口放在主菜单“团队歼灭 / 爆破模式 / 死斗模式”三个模式按钮下方，首次启动即可用默认配装直接开局。编辑页共用现有大厅背景，顶部切换 T / CT，中间为当前阵营的 15 个有序槽位，右侧为选中槽位可用的武器。武器卡显示名称、轮廓、局内价格和目前所在的槽位。步枪组标题下说明“步枪与狙击枪共用 5 位”。在较窄窗口保留槽位和候选两区，候选区单独滚动，底部保存操作始终可见。

1. 点槽位，再点候选即可替换。支持候选拖到槽位、同组两槽拖放互换，键盘也能完成点选路径。选择已在本组的枪时交换位置。跨组、跨阵营和重复占位在编辑时就给出原因。
2. T 的起始槽固定为 Glock-18。CT 可在 USP-S 与 P2000 间切换。首版将这三把候选专用于起始槽，各阵营其余手枪在另外 4 位中选择。配装以完整默认表开始，用替换维持 15 个有效且不重复的条目。
3. T / CT 分别保留编辑草稿；切换阵营不会丢失正在编辑的另一套。“恢复本阵营默认”只更新该阵营草稿。“保存”一次提交两套配置，返回大厅；有改动时直接返回，提供“保存并返回 / 放弃更改 / 继续编辑”。
4. 选择武器只改变本场商店清单。实际开局发放所选起始手枪，其余已入选枪械仍须按局内经济规则购买。允许在地面拾取并使用清单以外的枪，幸存者可按现有规则带入下一回合。

**首版默认值建议**，用于新玩家和旧档迁移。表内顺序就是初始快捷购买顺序，玩家可在大厅调整。

| 阵营 | 起始 ×1 | 其他手枪 ×4 | 中型 ×5 | 步枪与狙击枪合计 ×5 |
|---|---|---|---|---|
| T | Glock-18 | Dual Berettas、P250、Tec-9、Desert Eagle | MAC-10、MP7、UMP-45、XM1014、Negev | Galil AR、AK-47、SG 553、SSG 08、AWP |
| CT | USP-S | Dual Berettas、P250、Five-SeveN、Desert Eagle | MP9、MP7、UMP-45、XM1014、Negev | FAMAS、M4A4、M4A1-S、SSG 08、AWP |

## 四、代码落点与数据流

**大厅草稿 → 校验后存档 → 开局复制双阵营配置 → 根据当前阵营生成购买目录 → 游戏层在成交时再次判定。** 小鸡只共用轮盘的几何与输入，选中结果仍交给其原有回调。

| 落点 | 实施改动 |
|---|---|
| [武器定义](../PixelEngine/CS2D/Weapons/WeaponDef.hpp) | 在玩法层定义每阵营的起始位与 4/5/5 个有序槽位，提供默认配置、校验、是否入选以及按类别列举。依据 WeaponClass 和 WeaponDB::TeamAllowed 区分配装组、商店组与库存槽这三个概念。编辑页、商店和成交校验共用这些规则。 |
| [存档](../PixelEngine/Storage/SaveManager.cpp) · [设置结构](../PixelEngine/Storage/SaveManager.hpp) | 给渠道隔离的现有 INI 增加版本化的 T / CT 配装段，用稳定武器键保存各槽，例如 ct 的 rifle_1=m4a4。已有 menuWeapon 是旧大厅外观字段，独立保留。旧档无段就取默认；出现未知键、跨阵营、错误类型或重复时，保留有效槽位，优先按本组默认顺序补空，再取本目录中合法且未使用的条目。先完整校验草稿再一起保存。 |
| [状态定义](../PixelEngine/Core/Types.hpp) · [页面路由与输入](../PixelEngine/Engine.cpp) | 增加大厅配装页，接入转场、返回、鼠标模式以及静态背景回退。主菜单新增入口时同步更新中心按钮列与 overMenuButtons 的 3D 拾取遮挡范围，优先由同一布局结果生成两者。轮盘优先消费 Esc 与导航输入，再交给大厅、暂停或战斗。失焦、换页与强制关盘清理已按下扇区。 |
| [UI 接口](../PixelEngine/Graphics/GameUI.hpp) · [现有两种界面](../PixelEngine/Graphics/GameUI.cpp) | 提取一个扇形轮盘组件，接收中心、半径、稳定条目标识、图标及状态，输出进入、选择、返回、退款意图。用相邻内外弧采样点构成三角形绘制圆环；用半径和极角判定真实扇区。小鸡和商店各持自己的层级状态。替换 DrawFocusWheel 的多圈同屏按钮与 DrawBuyMenu 的三列卡片，沿用武器图标缓存。 |
| [开局与商店目录](../PixelEngine/Engine.cpp) · [玩法出生逻辑](../PixelEngine/CS2D/CS2DGame.cpp) · [回合复活](../PixelEngine/CS2D/CS2DGameRound.cpp) | 在 StartMatchWithMap 的 LoadMap 之前交付两套配置快照，选边完成后取对应阵营，覆盖延迟选边、重开及三种现有模式。SpawnPlayer 与 RespawnAllForRound 的默认发枪分支改读起始槽，使用实际 WeaponDef 初始化弹药。保枪分支照常。死斗继续记忆最近购买组合，重生时按本场阵营校验记忆项，失效则回到合法出生配置。BOT 沿用自己的采购策略。 |
| [购买契约](../PixelEngine/Core/PresentationContract.hpp) · [成交与退款](../PixelEngine/CS2D/CS2DGame.cpp) | RenderBuyMenu 从当前目录生成 BuyMenuCtx。EvaluatePurchase 在合法性、存活、时窗、区域与阵营检查之后、持有量及金额检查之前，拒绝未配装枪械，返回独立原因。ExecutePurchase 继续复核并负责扣款、库存、收据和真实结果。退款仍走 EvaluateRefund / ExecuteRefund。覆盖现有购买包装入口、开发回放的购买指令；调试用的直接发枪参数与玩家配装分开。 |

## 五、实施顺序与交付条件

| 阶段 | 工作与完成标志 |
|---|---|
| 1　固化配装规则 | 先落实目录、默认表、旧档补全和购买判定。在现有购买界面接入过滤，验证 UI 与直接购买请求对同一把枪给出一致结果。 |
| 2　打通赛前到出生 | 接入大厅编辑、保存、开局快照、换边和回合发枪。实际将 CT 起始改为 P2000、将 AWP 换成 AUG，重启游戏后进局核对出生武器和菜单。 |
| 3　用小鸡验证共享轮盘 | 在三只小鸡上走完两层选择、返回、持久化；用七色页检查最密扇区和鼠标边界。此阶段确认共享输入手感后再接入经济操作。 |
| 4　替换局内购买页 | 接入六类目录、二级成交、退货、动态状态、快捷键及关盘恢复瞄准。跑完买枪、购甲、投掷物连购与退款的连续操作。 |
| 5　集成验收 | 在实际游戏的爆破、团队歼灭和死斗中核对下表。记录使用的阵营、配装与模式，留存小鸡两层、购买两层以及赛前编辑页的截图。 |

### 可复现的验收用例

| 场景 | 操作与通过条件 |
|---|---|
| 双阵营和名额 | 两队各 15 个唯一且合法的槽位。在 CT 草稿用 AUG 替换 AWP，T 草稿仍有 AWP；两种 M4 可以共存。保存重启后展示与槽位顺序一致，取消编辑后下局沿用上次保存值。 |
| 地图与实际发枪 | 对局选 CT 后首回合以及需重发装备的回合均取得所选 P2000，对应弹匣与武器定义一致；幸存携枪进入下回合时保留原枪。切至 T 后使用 T 清单。死斗重生恢复合法的上一套购买组合，重开后使用新场次快照。 |
| 商店权限与库存 | CT 默认轮盘通过“狙击枪 → AWP”只扣一次；移除 AWP 后界面不可见，直接提交也返回“未配装”，钱和库存不变。在地上拾起 AWP 仍能使用。分别测试敌方专属枪、刀、C4、Zeus、两级护甲和 CT 拆包钳。 |
| 窗口、余额与退款 | 按下时能买、松开前超时或离开购买区，不能成交。钱不足、已拥有、投掷物总数上限均有正确原因。同回合买两枚闪光弹，第三次被拒；退一枚时只退一份。已用或跨回合物品按现有凭据拒退。 |
| 小鸡与存档 | 三只鸡分别改色、换姿势、戴上或摘下配饰，重进大厅和重启程序后逐只核对。七种羽色均能用鼠标和数字选中。悬停、拖出松开、点中心返回均不写入新值。 |
| 输入边界 | 一级点击不能在同帧触发二级；长按不连购；按下 A 扇区、移到 B 松开不成交。检查十二点接缝、中心死区、间隙与窗口失焦。二级 Esc 只退一级，买键收盘后第一帧无射击、切枪或准星跳变。 |
| 布局与兼容 | 在 1280×720、1920×1080、1920×1200，以及至少一种高 DPI 或窗口缩放下复测圆心、边缘和细扇区。检查“护甲+头盔”与较长枪名可读、两层图标不越界、大厅新增入口不点穿小鸡、3D 背景不可用时仍可编辑配装。 |
| 旧档与损坏数据 | 用无配装段旧档、重复 ID、跨阵营项和未知 ID 分别启动；两队都能开局，仅问题槽被修复，原小鸡外观与其他设置保留。 |
