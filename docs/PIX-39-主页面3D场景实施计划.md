## 1. 现状（先读，不要猜）

- 三场景轮换：`ancient_ruins` / `dust_2` / `mirage`，切换时 0.5 秒交叉淡入；预览图由 `CaptureScenePreviews()` 在启动时实时抓拍。
- 当前 dust_2（`assets/models/menu/scenes/dust_2.glb`，约 1.0 MB）：19 网格、30 primitive、12 种纯色材质、约 56,682 顶点、0 贴图、1 个风动剪辑（18 通道）。来源 `tools/menu-scenes/create_scenes.py` 程序化生成——立方体/圆柱/球体拼的盒子房子、拱门、板条箱、铁桶、棕榈、一辆盒子车。这就是「太简单」。
- **相机固定**：主相机 eye `(0, 1.05, 8.0)`、look `(0, 0.95, 0)`；另有 focus 相机 `(2.00, 8.6)` 和一个俯视扫过镜头。Blender 预览相机 `(0,3,12)`、28mm。所有设计以主相机为准，兼顾另外两个角度。
- 环境已就绪：Blender 5.2.3 LTS 在 `D:\Blender\blender.exe`（不在 PATH，用完整路径）；Codex 的 MCP 已配置（`~\.codex\config.toml`，`[mcp_servers.blender]`，mcp-for-blender，127.0.0.1:9876）。

## 2. 艺术方向（AAA 标准，按这五条做）

### 构图——先为固定相机设计，再谈细节

- 以主相机为唯一主视角：三分法布局，视觉重心放在**中路双门**（画面中心偏右的黄金点）；Xbox 与猫道形成引导线，把视线从前景引向纵深。
- **三层纵深**：前景（沙袋/木箱/近景道具，可以做得丰富醒目）、中景（双门/Xbox/猫道，视觉主体）、远景（屋顶剪影 + 天空，压暗、去饱和，形成空气透视）。三层之间要有明确的空间间隔，不要糊成一堵墙。
- **剪影可读性**：每个英雄道具在主相机视角下轮廓必须一眼可辨，不靠贴图认东西；先看剪影，再看细节。白模阶段就用剪影验收。
- 负空间：画面上方留天空，下方留地面，主体不顶满画面。**建模时不用给角色与界面留空**：角色位置与界面布局事后按新场景重新排布。

### 色彩脚本——主色克制，点缀色大胆

- 主色：沙黄（墙面、地面）+ 石灰（石质拱门、台阶），低饱和、大面积。
- 点缀：**绿门**（全场最饱和的一块，视觉锚点）、锈红（铁桶、锈迹），高饱和、小面积。不要满屏高饱和。
- 冷暖对比：暖阳 + 冷色阴影与天空（带一点蓝灰），阴影面不死黑。
- 材质色差：同一材质至少 2–3 个深浅变体，避免大面积平色——大面积平色就是现在盒子感的来源之一。

### 光照——影子是构图的一部分

- 主光：暖色阳光，低角度、长影，方向全场一致；门洞、箱子、拱门的投影要有形状，不要只有明暗。
- 补光：天空冷色环境光，阴影面留细节；Blender 预览沿用现有做法——Area 灯（圆盘、能量 1700、尺寸 12）、世界底色 `(0.23, 0.25, 0.28)`。
- 轮廓：英雄道具边缘要有亮面/暗面对比，立得住；避免所有面同一亮度。

### 材质与贴图——三种材质一眼分得开

- 贴图只用在关键表面（门板、木箱、墙面、地面）：木纹、铁锈、石材、沙地各做一张，单张 ≤ 2048px；贴图要有磨损、污渍、风化，不要干净得像新的一样。
- 粗糙度变化：金属门（较光滑、局部反光）、木箱（粗糙、纹理明显）、石墙（哑光、颗粒感）——三种材质一眼分得开。
- 边缘磨损：所有硬边做倒角 + 磨损色（边角磨亮/掉漆），不要有锋利的 CG 棱角。
- 贴图来源：自制优先；第三方只用 CC0 / CC-BY，写进 `assets/models/CREDITS.md`；**绝不用 Valve 的原版贴图**。

### 细节层次与氛围——让人觉得这地方有人住过

- **英雄道具**（双门、Xbox、猫道）做到最高密度：铆钉、把手、合页、木纹、台阶磨损、扶手锈迹。
- **中景**（沙袋、木箱、铁桶、房屋立面）次之：沙袋一排排弧形堆叠、木箱木纹错开、窗户百叶/封窗/破窗各不相同。
- **远景**只做剪影与色块，不堆细节。
- 生活痕迹：散落的碎石、沙堆、墙上海报/涂鸦色块、电线杆与电线、路灯、垃圾桶、废弃汽车（比现在盒子车精细：车身弧线、车窗、轮胎、锈迹色块）。每个细节都要有落点，加不进构图的细节不做。
- 氛围：午后沙漠小镇，干燥、明亮、略带风沙感；风动（棕榈叶、旗帜、篷布）轻微摆动，0–120 帧循环；远景加淡淡的暖色雾感（用底色与去饱和表现，不用真雾效）。

## 3. 场景内容：de_dust2 中路（按层次，至少做到这些）

> 清单是**底线，不是天花板**。每件都写了「怎么做」「做到什么程度」「还能往哪推」：前两项是验收线，必须达到；第三项是发挥空间——看到能加分的地方就加上，有更好的想法就按更好的做，只要符合第 2 节的美术方向与第 6 节的规则。**不要只照着清单打勾了事。**

**中景（视觉主体）**：

1. **中路双门**——怎么做：门板分块建模（左右两扇 + 门框 + 上方横梁），铆钉、把手、合页做几何，不要只画贴图；门缝透一点光。做到什么程度：近景英雄级，走到主相机前能看清铆钉排列与把手造型，门板有铁锈与磨损贴图。还能往哪推：门板下沿锈穿、门框裂缝、门后透出的暖光、门上贴的告示/涂鸦。
2. **Xbox**——怎么做：木板拼接建模（板缝、钉子），木纹贴图，深浅两种木色错开，边角倒角磨损。做到什么程度：顶部与侧面木纹清晰，边角有磨亮的磨损带。还能往哪推：顶部划痕、弹孔、压扁的易拉罐、搭在上面的破布。
3. **猫道楼梯**——怎么做：台阶逐级建模 + 扶手 + 平台 + 侧面挡板，台阶踩踏面做磨损。做到什么程度：台阶数量感与高度差一眼可数，扶手有锈迹。还能往哪推：台阶边角破损、扶手松动的歪斜、平台上的沙袋或杂物。
4. **A 小拱门**——怎么做：石块拼接感（拱顶弧线 + 石块分缝），门洞后暗色通道，墙面剥落贴图。做到什么程度：拱形轮廓干净，石块接缝可见。还能往哪推：拱顶裂缝、垂下的电线、门洞里透出的冷色光。

**前景/中景（掩体与立面）**：

5. **沙袋墙 + 木箱堆 + 铁桶**——怎么做：沙袋逐个建模，弧形堆叠（不要一个方盒子了事），布纹贴图 + 扎口；木箱木纹错开；铁桶做凹痕与锈迹。做到什么程度：沙袋一排排的弧形堆叠感在主相机下可辨，木箱与铁桶材质一眼分开。还能往哪推：沙袋上散落的沙土、木箱上的 stencil 字、铁桶里的杂物。
6. **两侧房屋立面**——怎么做：窗户三种做法各不相同（百叶窗、木板封窗、破窗），阳台、屋顶线、烟囱/通风管、墙面裂缝与剥落用贴图与色块表现。做到什么程度：左右立面不重复，窗户类型至少三种。还能往哪推：阳台上的杂物、晾衣绳、空调外机、墙面涂鸦。
7. **地面**——怎么做：石板路拼接（板缝）+ 沙地，裂缝、沙堆、散落的碎石用几何 + 贴图。做到什么程度：地面不是一张平色，有石板与沙地的材质区分。还能往哪推：车辙印、弹坑、脚印。
8. **细节道具**——怎么做：棕榈叶片分层建模（带风动）、废弃汽车（车身弧线、车窗、轮胎、锈迹色块）、电线杆 + 电线（电线要有垂度）、墙上海报/涂鸦、路灯、垃圾桶。做到什么程度：每件道具在主相机下能认出是什么，汽车不是盒子车。还能往哪推：汽车后视镜、车牌、路灯的暖光晕、垃圾桶旁的纸团。

**远景**：

9. **屋顶剪影 + 天空底色**——怎么做：屋顶轮廓剪影 + 天空底色做背景板，压暗、去饱和。做到什么程度：远景有层次，不是一片平色。还能往哪推：远处烟囱的烟、飞鸟剪影、晚霞色带。

> 预算分配原则：细节密度优先花在英雄道具（双门、Xbox、猫道）上；如果顶点/材质预算吃紧，先保中景主体，远景剪影可以省——不要为了凑数把预算撒在看不清的地方。

- **贴图支持是本次任务的一部分**：扩展 `Menu3DModel`，加 UV 解析、贴图加载、纹理管线。只加新能力，不改现有相机参数、加载逻辑、0.5 秒切换、预览抓拍。
- **源文件**：`tools/menu-scenes/dust_2.blend`（改这里）。**生成脚本**：`tools/menu-scenes/create_scenes.py`——把新场景的建造逻辑写进脚本，保证可重复生成，**不要只改 .blend 不改脚本**（现在三个场景都是脚本生成的，这是项目的规矩）。
- **导出**：`assets/models/menu/scenes/dust_2.glb`；GLB 格式、动画用 NLA、强制采样、不导出相机/灯光；导出前按材质合并网格；**贴图打进 GLB**（嵌入式，不外挂文件）。
- **预算**：顶点 ≤ 150,000（现在约 56,682）；GLB ≤ 8 MB（含贴图，原来纯色版约 1.0 MB）；材质 ≤ 32 种（2026-11-24 Sun 批准从 24 上调，允许新增贴图集）；贴图单张 ≤ 2048px。主菜单帧率不低于改动前。
- **风动动画**：保持恰好 **1 个剪辑**，名 `Menu_Environment`，0–120 帧、30fps 循环。`create_scenes.py` 里有断言要求 18 个通道——如果增减风动叶片，同步更新断言里的通道数，并在交付说明里写明改了多少。
- **坐标约定**：Blender Z 为高度，Blender -Y 对应游戏 Z；地砖顶面高度 0，基础地面顶面 -0.02（防共面闪烁）。
- **校验**：`D:\Blender\blender.exe --background --python tools/menu-scenes/validate_scenes.py`，必须 0 findings 才能算完（保护区定义按新场景更新后，见第 5 节第 5 步）。

## 5. 执行流程（五步，每步有门，不过不进下一步）

1. **白模与构图**：先用简单几何搭出双门/Xbox/猫道/房屋/地面的位置与比例，主相机截图确认构图、三层纵深、剪影可读。这一步不过，不进细节。
2. **几何细节**：按第 3 节每件的「做到什么程度」做到位，「还能往哪推」自由发挥；英雄道具最细，中景次之，远景剪影；每完成一个大件导出一次 GLB 验证，不要攒到最后。

4. **光照与氛围**：按第 2 节布光，调主光方向与阴影、补光、世界底色；主相机、focus 相机、俯视镜头各截一张图检查。
