## 二、逐项验收

### 1. 人物描边仍在抖动

| 项 | 结果 |
|---|---|
| 根因 | 上一轮只删掉了 `DrawCharacter` 里的行走 bobbing，但描边遮罩走的是**另一份**变换 `BodyGeometry::Transform()`——里面还留着 `bob = sin(timer*12) * 1.2f`。角色本体不动、1px 描边却按旧正弦曲线跳动，所以只有描边在抖 |
| 修复 | 删除 `BodyGeometry::Transform()` 中的 bob 分支，与 `DrawCharacter` 完全对齐（射击后坐的 `kick` 保留） |
| 断言 | `Walk` 的 8 个相位与 `Idle` 的中心点逐位相同；任意相位下身体中心都落在体内；射击后坐位移仍在 |

证据：`build-evidence/pix38/outline-no-bob.png`（5 个行走相位完全对齐）。

### 2. 人物进入烟雾没有效果

| 项 | 结果 |
|---|---|
| 根因（真 bug） | 上一轮把烟雾透明度写进了 `SpriteDrawParams::alpha`，但绘制角色时用的可见性过滤器 `worldVisible` **包含** `!smokeBlocked(x,y)`——角色一进烟就被**整块硬剔除**，根本轮不到 alpha 生效。所以"透明度方式"永远看不到 |
| 修复 | 新增 `actorVisible` 过滤器：只做视野锥/墙体判定，**不含烟雾**。BOT 与玩家改用 `actorVisible` 绘制，烟雾完全交给 `sp.alpha`（由 `SmokeOpacityAt` 驱动）处理 |
| 语义保持 | 地面层/掉落物/爆炸粒子仍用 `worldVisible`（烟雾照旧遮挡视野）；玩家自己的身躯仍用 `ownBodyVisible` |
| 断言 | 无烟 alpha=255；浓烟 alpha 下降但 >0（保留淡影，不凭空消失）；烟边缘比烟心更可见；烟散 alpha 回升；清空烟雾恢复 255 |

证据：`build-evidence/pix38/smoke-actor-fade.png`（从烟外到烟心逐级变淡）。

### 3. 燃烧弹素材太大，再缩到 1/16

| 项 | 结果 |
|---|---|
| 尺寸系数 | 单块贴图由 `0.26·r` 改为 `0.065·r`（线尺寸 ×1/4 → **面积 1/16**），下限 8 → 4 世界单位 |
| 火区范围 | **不变**：`Tuning::FireRadius` 仍为 60，`FireEffectiveRadius` 未改，判定与伤害范围完全一致 |
| 断言 | 单块面积 / 上一轮面积 = 1/16（±2%）；贴图确实更小；火区半径与有效半径不变 |

实测：`activeR=60.0, tile=4.0`。证据：`build-evidence/pix38/fire-tiles-smaller.png`。

### 4. 准星跟随武器后坐力扩散

| 项 | 结果 |
|---|---|
| 现状 | 准星间隙只加移动扩散 `GetCrosshairBloom()`，开火不张开 |
| 新增 | `CS2DGame::GetRecoilBloom()`：取本武器弹道累积散布 `BallisticInaccuracy()` / 6，饱和到 0..1。与移动扩散**分别计算、表现层相加**，所以"边走边打"不会互相吞掉 |
| 表现 | `CS2DOverlay` 的准星 gap += `(moveBloom + recoilBloom) * CrosshairBloomMaxPx * uiScale` |
| 断言 | 未开火为 0；连射 6 发后上升且 ≤1；停火后回落；移动扩散与后坐扩散可同时非零 |

### 5. 雷达中的地图边缘加上拓展

| 项 | 结果 |
|---|---|
| 现状 | 雷达底图只铺「地图本体」那一个内接矩形，四周是空的；选阵营界面用的是 perimeter 场景图（比地图本体大一圈） |
| 修复 | `BuildRadarTexture()` 在铺地图本体**之前**，先把同一套 `perimeterTex_`（按 `perimeterWorldRect_` 的世界范围、以地图本体的缩放为基准）铺一层（alpha 165），再压上不透明的本体——延伸只在外圈可见 |
| 断言 | perimeter 场景范围确实大于地图本体；雷达底图在带 perimeter 的情况下仍能正常烘焙出纹理 |

### 6. 结算界面场景切换跨度太小

| 项 | 结果 |
|---|---|
| 根因 | `ShowcaseCamera::Sample` 把中心锁在少数几个出生点/区域中心，只用 `rangeX * 0.22` 在附近晃 —— 每次切换几乎原地不动 |
| 修复 | 改为「黄金比低差异序列」在合法中心矩形内铺点（两个无理数分别驱动 x/y），相邻 shot 的归一化坐标相差约 0.618 / 0.382；再叠小幅往复漂移保证画面不是静态的 |
| 缩放档位 | 由 `{1.22, 1.62, 1.38, 1.86}` 改为 `{1.55, 2.15, 1.78, 2.60}`。原因：合法中心矩形 = 地图 − 2×半屏；1.22 档只剩地图的 18%，无论怎么铺点都挤在一起 |
| 断言 | 相邻机位位移 > 0.15 地图（实测 **0.202**，旧实现 0.074）；12 个机位覆盖全部四象限；缩放在 4 档之间交替；传入据点吸附时仍覆盖四象限 |
| 去重 | `Engine.cpp` 里硬编码的 `6.8f` 改为引用 `ShowcaseCamera::kShotSeconds`，避免两处魔法数字漂移 |

## 五、说明与观察项

- **烟雾渐隐的取值**：最浓处保留约 12% 可见度（`keep = 1 - 0.88*opacity`），刻意不做成全透明，避免"人凭空消失"。若目检觉得太淡/太亮，改这一个系数即可。
- **火焰贴图下限 4 世界单位**：半径 60 的火区实际 tile = 4（`0.065*60 = 3.9` → 取 4）。若觉得太碎，调 `0.065` 系数即可，火区范围不受影响。
- **雷达延伸的可见度**：perimeter 用 alpha 165 叠在地图本体之下，本体边缘会被本体压住，只有外圈露出来；在小尺寸雷达上可能偏淡，需要目检定夺。
- **结算机位**：仍保留 12% 的「向据点收敛」，所以机位会偶尔把包点/出生点框进画面；跨度的硬保证来自低差异序列。
- **上一轮遗留**：PIX-37 的 `DrawBombCarrierMarker` 声明与 `WALK_BOB_AMPLITUDE` 常量在上一轮已清除，本轮复查无残留死代码。
