# UI 规范（CS2D 风格）— PIX-6 基线

本文件是 UI 的唯一视觉基线：色值、字号、间距、控件状态、缩放与可访问性规则。
代码里的单一来源是 `Graphics/Palette.hpp`（通用色）与 `Graphics/TeamVisualStyle.hpp`（阵营色），
新增颜色**必须**加在这两处，不要在 `GameUI.cpp` 里写新的魔数。

## 1. 设计基准与缩放

| 项 | 值 |
| --- | --- |
| 设计基准 | 1920 × 1080（`Graphics/UiScale.hpp` 的 `kDesignW/kDesignH`） |
| 缩放系数 | `g_uiScale = min(logicalW/1920, logicalH/1080)`，范围 0.35–4.0 |
| 写法 | 所有尺寸都写设计值再乘 `UI(x)`（宏），**禁止**用物理像素或再次缩放 |
| 内部画布 | 高度锁定 1080，宽度按窗口比例；窗口/全屏/渲染缩放都走同一套 `UI()` |

## 2. 颜色令牌

### 2.1 背景与边框（`Palette`）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `BgDeep` | `#0B0F14` (0.043, 0.059, 0.078) | 页面底色、HUD 半透明底 |
| `BgPanel` | (0.075, 0.098, 0.125) | 卡片/面板底 |
| `BgPanelHi` | (0.110, 0.140, 0.180) | 面板内的分组底 |
| `BgHover` | (0.150, 0.185, 0.235) | 悬停底 |
| `Border` / `BorderHi` | 0.22/0.26/0.32 α0.65 · 0.36/0.42/0.50 α0.9 | 常态边框 / 高亮边框 |
| `Accent` | `#EDA E4D` 近似 (0.930, 0.680, 0.300) | 沙漠金主强调（标题装饰、选中、关键数值） |
| `AccentSoft` / `AccentDim` | 同色 α0.55 / 暗一档 | 次级强调 / 不可用强调 |
| `Text` / `TextDim` / `TextFaint` | (0.925,0.940,0.960) / (0.560,0.625,0.700) / (0.400,0.455,0.520) | 正文 / 次要 / 弱提示 |

### 2.2 语义色

`Danger`（失败/危险）· `Ally`（友方/成功）· `Info`（信息/链接）。

### 2.3 阵营色（`TeamVisualStyle`）

| 阵营 | 主色 | 形状 | 文本 |
| --- | --- | --- | --- |
| CT | 冷蓝 `#58A8F5` (88,168,245) | 圆形徽标 | `CT` |
| T | 暖橙 `#F0A046` (240,160,70) | 菱形徽标 | `T` |
| None | 中性灰 (150,160,170) | 中性 | `-` |

规则：**颜色 + 形状 + 文本三者同时出现**，任何只靠颜色的区分都视为不合格（色弱、低饱和地图、
灰度截图下仍需可辨）。

## 3. 字号阶梯

`ImGuiUI::GetFont(size)` 取最接近档位的字体；下表是实际使用的设计字号（乘 `UI()` 前）。

| 用途 | 设计字号 | 位置示例 |
| --- | --- | --- |
| 页面大标题 | 32 | 设置/历史/地图选择页标题 |
| 区块标题 | 26 | 模式名、阵营名、购买分类标题 |
| 数值/强调 | 28–30 | 比分、剩余时间、余额 |
| 正文 | 16 | 说明段落、设置项标签、卡片副标题 |
| 辅助/脚注 | 12 | 规则说明、快捷键提示、tab 名 |

层级原则：**一屏内最多两级标题**；正文与辅助文字只用 `Text` / `TextDim` / `TextFaint` 三档，
不得再引入新的灰阶。

## 4. 间距与栅格

| 项 | 设计值 |
| --- | --- |
| 页面外边距 | 72 |
| 卡片内边距 | 28（`labelX`） |
| 卡片标题区高度 | 62（`header`） |
| 设置行高 | 44 |
| 列表行高（弹窗/比分板） | 56 |
| 卡片间距 | 16 |
| 控件最小点击高度 | 32（按钮 42–48 为主操作） |
| 圆角 | 面板 10、按钮 4–6 |

## 5. 控件状态

| 状态 | 视觉 | 备注 |
| --- | --- | --- |
| 常态 | `BgPanel` 底 + `Border` 边 | — |
| 悬停 | `BgHover` 底 + `BorderHi` 边，文字提亮 | 指针反馈必须即帧生效 |
| 按下 | 底色比悬停再亮一档 + 边 `Accent` | 与"选中"区分：按下是瞬时 |
| 选中 | `Accent` 左边条（3px）+ 文字 `Accent` | 用于分类 tab、轮盘选项 |
| 禁用 | 底色不变、文字 `TextFaint`、**保留原因文本** | 不用纯 alpha 降低可读性 |
| 成功 | 文字/图标 `Ally` + 1.6s 短提示 | 仅在业务层确认成功后显示 |
| 失败 | 文字 `Danger` + 2.2s 短提示，写明具体原因 | 原因来自 `BuyCode` 等业务枚举 |

## 6. 布局与断点

| 视口 | 要求 |
| --- | --- |
| 1280×720 | 关键信息不截断；卡片可滚动；字号由 `UI()` 等比缩小后仍 ≥ 12 设计值 |
| 1920×1080 | 基准视图，作为截图对照 |
| 16:10（2560×1600） | 只用等比缩放 + 居中，不拉伸 |
| 窗口↔全屏 | 切换后重算 `g_uiScale`，无重叠/负坐标 |

## 7. 可访问性与"不只靠颜色"

1. 阵营：颜色 + 形状（圆/菱形）+ 文本标签。
2. 购买项：图标轮廓 + 类别文本 + 价格；禁用项保留原因文本。
3. 低血/空弹：颜色 + 数值 + 文案（"换弹中"等），不只靠红色。
4. 所有交互控件都有 `##id` 稳定标识，避免 ImGui ID 冲突导致状态串台。

## 8. 禁止事项

- 不在页面里写新色值/新字号魔数（必须走 `Palette` / `TeamVisualStyle` / `UI()`）。
- 不用整文件格式化或批量改名制造噪音 diff。
- 不改武器数值、经济、BOT、视野规则来"配合 UI"（那些是玩法层的事）。
- 开镜期间不绘制第二层镜框或第二个准星（由 PIX-10 的 `DrawScopeOverlay` 独占）。
