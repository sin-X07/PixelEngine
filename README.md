# PixelEngine — CS2D-like 单机版

C++17 / SDL2 的俯视角 2D 战术射击游戏，玩法对标 Steam 的 **CS2D**。
玩家（CT）与 LLM 驱动的 BOT 进行 5v5 对抗。

---

## 当前玩法

| 模式 | 说明 |
|---|---|
| **团队歼灭** | 回合制 T/CT 对抗，歼灭对方全部成员或时间到守方胜 |
| **爆破** | T 在包点下包，C4 40 秒倒计时；CT 需拆包 |
| **人质营救** | CT 营救全部人质，T 需阻止 |
| **死斗** | 自由击杀，即时重生，无回合 |

### 核心系统

- **回合制**：`冻结 → 购买 → 交战 → 结算` 四阶段循环，先到 8 分获胜。
- **经济（照抄 CS2）**：起始 $800、上限 $16000；回合胜利 +$3250；
  失败按连败递增 **$1400 / $1900 / $2400 / $2900 / $3400**（封顶）；
  T 下包成功后 **T 全员 +$300/人**；CT 拆包成功 **拆包者个人 +$300**。
- **击杀奖励（按武器类型，照抄 CS2）**：步枪/手枪/机枪/手雷 **$300**；
  SMG **$600**（P90 特殊 **$300**）；霰弹枪 **$900**；狙击枪 **$100**；
  刀 **$1500**；Zeus **$0**。
- **开局装备（照抄 CS2）**：双方都**只有起始手枪、无护甲、无投掷物**——
  CT 拿 **USP-S**，T 拿 **Glock-18**。每回合重置回该状态；
  步枪 / 护甲 / 手雷全部靠经济购买，玩家与 BOT 共用同一套价格。
- **阵营隔离（照抄 CS2）**：T 与 CT 的可购武器互不相通——
  T 专属：Glock-18 / Tec-9 / MAC-10 / Galil AR / AK-47 / SG 553 / G3SG1 /
  Sawed-Off / 燃烧瓶；CT 专属：USP-S / P2000 / Five-SeveN / MP9 / FAMAS /
  M4A4 / M4A1-S / AUG / SCAR-20 / MAG-7 / 燃烧弹；
  其余（AWP、Deagle、P250、CZ75、SSG 08、Nova、XM1014、M249、Negev、
  高爆雷、闪光弹、烟雾弹、诱饵弹）双方通用。
- **持械移速**：拿着不同武器移速不同（匕首 1.00 > 手枪 0.92/0.88 > SMG 0.86 >
  霰弹 0.84 > 步枪 0.80 > AWP 0.72）。玩家与 BOT 共用同一套倍率。
- **画面适配**：内部画布**高度锚定 1080**、宽度按窗口比例（无黑边、内容不丢失）；
  UI 按 1920×1080 设计基准**等比缩放**（字体 + 控件尺寸）。
  分辨率下拉框只决定**窗口大小**；另有「渲染缩放 100/75/50%」单独控制内部画布精度。
- **显示设置**：分辨率 = **窗口大小**，与内部渲染解耦。
  窗口模式窗口尽量按该尺寸开（超出桌面会被裁到可用区），全屏模式铺满桌面但
  仍按所选分辨率渲染（比例不符时自动加黑边）。共 18 档常见分辨率：
  16:9（720p/768p/900p/1080p/1440p/4K）、16:10（800/900/1050/1200/1600）、
  4:3（600/768/960/1200）、5:4（1024）、21:9（1080/1440）。
- **LLM 教练管线**：固定 system 前缀（角色/词表/区域表）+ 短状态摘要（比分/经济/
  存活/炸弹/已知敌人区域/上条指令/教练笔记），`max_tokens=150`、温度 0.3、
  `cache_prompt`，尝试 `response_format:json_schema`（服务端不支持时自动回退）。
  每回合最多 8 次调用，关键事件 + 8 秒心跳；计划带 `ttl_s`（3~30 秒），
  回包时回合号或炸弹状态变化即丢弃；回合结束追加一次「一句话复盘」进滚动笔记。
- **对局历史**：主菜单「历史记录」查看最近 50 场（时间 / 模式 / 地图 / 比分 /
  胜负 / K-D / 回合数 / 时长），完成一场比赛后自动写入 `cs2d_history.txt`。
- **投掷物**：按住左键蓄力，**松开才出手**；出手瞬间播放投掷音效。
- **地图选择**：爆破模式进入前会打开地图选择界面（卡片 + 预览图 + 快捷键）。
  目前可选：古代遗迹（29 区域）、沙漠Ⅱ（35 区域）、荒漠迷城（32 区域）。新增地图只要在
  `CS2D/MapCatalog.hpp` 里加一条即可。
- **买枪**：**回合开始后 15 秒内**都可按 `B` 打开菜单（覆盖冻结 + 购买 + 交战初期，
  离开窗口自动关闭），需在己方购买区内且余额充足；买完自动装备。
- **准备阶段**：冻结期可以**转向瞄准**，但不能移动、不能开火。
  回合结算展示期可以移动与拾取装备，但同样不能开火。
- **拆包**：按住 `E` 期间**不能射击**；松开或离开范围，进度**立刻归零**。
- **投掷物**：一局最多带 **4 个**；闪光可带 **2 个**，其它每种只能 1 个；
  每个投掷物**只能用一次**，用掉即从背包移除。按 `4` 在背包内的投掷物之间循环切换。
- **武器库（36 种，照抄 CS2）**：
  - **手枪**：Glock-18 / USP-S / P2000 / Dual Berettas / P250 / Five-SeveN /
    Tec-9 / CZ75-Auto / Desert Eagle / R8 Revolver / Zeus x27（1 发无备弹）
  - **冲锋枪**：MAC-10 / MP9 / MP7 / MP5-SD / UMP-45 / P90
  - **步枪**：Galil AR / FAMAS / AK-47 / M4A4 / M4A1-S / SG 553 / AUG
  - **狙击枪**：SSG 08 / AWP / SCAR-20 / G3SG1
  - **霰弹枪**：Nova / XM1014 / Sawed-Off / MAG-7
  - **机枪**：M249 / Negev
  - **投掷物**：高爆雷 / 闪光弹 / 烟雾弹 / 燃烧瓶(T) / 燃烧弹(CT) / 诱饵弹
  - **近战**：匕首。主/副/近战/投掷四个槽位。
- **手雷**：高爆范围伤害、闪光致盲、烟雾遮挡双方视线。
  高爆雷爆炸半径 110，伤害按**平方衰减**（0px=78 / 30px=41 / 60px=16 / 90px=2）；
  投掷后与爆炸时都会画出伤害范围。
- **换弹**：每把枪有独立换弹时长（取自对应 `*_reload.mp3` 实测长度：
  USP 1.49s / Glock 1.99s / Deagle 1.31s / M4A1 1.75s / Galil 1.83s /
  AK-47 2.74s / AWP 3.16s / 霰弹枪 1.10s），换弹时播放对应音效（3D 定位）。
- **备弹**：每把武器的备弹上限 = **弹匣容量 × 3**（如 AK-47 30 发弹匣 → 90 发备弹），
  **不是无限子弹**。换弹时从备弹扣取，备弹耗尽后无法再换弹（HUD 显示为 `弹匣/容量 (+备弹)`）。
  每个武器槽各自保存自己的弹匣与备弹，切枪不会互相串味。
- **掉落**：阵亡时按 主武器 → 副武器（非标配手枪）→ 随机一个投掷物 的顺序
  掉落一件装备；**保留到本回合结束**。空槽位路过会自动拾取（不切换手持武器），
  按 `E` 可主动拾取并替换；按 `G` 丢弃当前武器（近战除外）。
  **掉落会记录丢弃瞬间的弹匣与备弹**，捡起时原样恢复（BOT 打剩一半的枪捡起来就是一半），
  不会凭空变成满弹。
- **弹药耗尽**：BOT 的弹匣与备弹都打光后会切换到仍有弹药的武器，最后退到近战，
  不会站着空放或反复无效换弹。
- **道具伤害**：高爆/闪光对**所有人**生效（含己方与投掷者）；
  投掷物按子步进做碰撞检测，不会穿墙。
- **脚步声**：玩家与所有 BOT 都有脚步声（3D 定位），潜行时不发声。
- **护甲**：护甲吸收 50% 伤害（配头盔 60%），护甲按吸收量消耗，耗尽后头盔失效。
  在买枪菜单「护甲」分组购买（$650 / $1000）。
- **目标物**：C4 下包/拆包、人质营救。玩家按住 `E` 拆包/救人；
  **CT BOT 贴近炸弹会自动拆包**（玩家阵亡后仍可赢下回合并）。
  已安装的 C4 有红色脉冲标记，并画出**拆包有效范围（半径 26，必须贴身）**；
  下包后 **T BOT 会围绕包点环形站位死守**，并优先集火靠近包点的 CT。
- **视野**：以玩家朝向为中心的 **120° 扇形**（半径 100 世界单位，含 14° 角度软边，
  实际约 ±67° 可见）+ 墙体遮挡。扇形外完全不可见，背后和侧面都是盲区。
  镜头缩放按「视野圆刚好装进较窄的一边」自动计算，并允许镜头越界一个半径，
  保证扇形在任何屏幕比例下都完整可见。队友始终可见。
- **致盲**：闪光弹生效期间**完全丧失视野**（整屏不透明，最后 0.4s 淡出）。
  BOT 同样会失明——看不到敌人，也无法向队友上报情报。
- **回合装备继承**：回合结束时**存活**的人保留手上的武器/护甲/投掷物；
  **阵亡**的人下回合回到手枪。对玩家和所有 BOT 一视同仁。
- **BOT 战术协同**：每回合按距敌远近分配 **突破 / 支援 / 断后** 三种角色
  （行进速度 1.0 / 0.8 / 0.55，断后位无任务时不主动追击）；
  每 0.5s 重选**集火目标**，评分同时考虑队友密度（集火）与
  「换弹/低血队友」附近的敌人（掩护）。
- **BOT 视野**：与玩家**同一套 120° 扇形几何**——背后的敌人看不见，也上报不了。
  为了不至于变瞎，BOT 有配套的朝向行为：无目标时原地缓慢扫描（≈57°/s），
  行进时左右小幅摆头（±26°），中弹瞬间立刻转向威胁。
- **BOT 探点与情报**：交火半径 100px；200px 内（且在扇形内、无遮挡）看到敌人
  会向本队上报，情报保留 6s。集火与推进都基于这份共享情报。
  爆破图中 **T 分队进攻 A/B**（轮转分配，不再只打一个点），
  **CT 分兵守 A / B / 中路**，无情报时在本岗位附近活动；
  会用**手雷**攻击情报点（冷却 7s）。
- **BOT 听声扑人（下包 / 拆包）**：声音比视野传得远——**300px** 内（远大于 100px 视野）
  - **T 正在下包**：该范围内的 **CT BOT 立刻放弃驻守，优先扑向安装者**；
  - **CT 正在拆包**：该范围内的 **T BOT 立刻放弃守包，优先扑向拆包者**。
  听声锁定不需要目标在视野扇形内（声音不分朝向），此时散布乘数降到 **0.72**（更准），
  但仍需**真实视线**才开火——隔着墙只会循声逼近，不会隔墙射击。
- **BOT 经济与撤退**：BOT 与玩家共用一套经济（回合奖金 + 击杀奖励），
  每回合按余额买护甲（$650/$1000）和武器（AWP / AK-M4 / Galil / SMG / 霰弹）。
  血量 ≤30 时会跑向掩体（要求该点看不见威胁）并边走边换弹。
- **3D 音效**：声像由声源相对玩家的**世界位置**决定，转视角时左右声道不会翻转；
  260 单位内不衰减，之后线性衰减到 **12% 底噪**（900 单位外仍然能听到远处交火）。
  枪声按武器区分，C4 滴答越近越急促。混音通道 32 个，避免混战丢音。
- **比赛结束**：任一队先到 8 分即结束，回合状态机冻结，屏幕显示获胜方，
  8 秒后自动返回主菜单（死斗模式无比分，不会结束）。
- **打击反馈**：开枪有枪口火焰；命中敌人时准星出现 X；被击中时屏幕四周泛红。
- **HUD**：左下角血量条（绿/黄/红）+ 护甲条（蓝色，含头盔标记）。
- **雷达**：用**地图背景图缩放烘焙**成底图（无背景时用碰撞网格烘一层），
  支持设置里的 居中/旋转/缩放/透明度/尺寸。
- **LLM 教练（唯一的 LLM 消费者）**：本地 `llama-server` 只产出**战术计划**
  （意图 / 目标点位 / tempo / 五个角色槽位），决策上下文包含阵营、回合阶段、比分、金钱、
  任务目标。**LLM 不驱动 BOT 的任何具体行动**——移动、瞄准、射击节奏全部由决策树决定，
  教练计划只通过「去哪、什么节奏」间接影响它们。LLM 不可用时自动回退规则教练。
- **BOT 行动层**：纯决策树。每帧推导姿态（强攻/固守/撤退/借掩体）与射击纪律
  （连发/点射/停火），移动一律走 A* 寻路 + 碰撞检测，不存在绕过地图的脚本位移。

## 构建与运行

前置：CMake 3.16+、MinGW-w64（x86_64 UCRT）。SDL2 / SDL2_mixer / SDL2_image
通过 FetchContent 自动下载并校验 SHA-256。

```powershell
cmake --preset mingw-debug
cmake --build build
.\build\EngineApp.exe
```

### 调试参数

```powershell
EngineApp.exe --autostart             # 跳过菜单直接开局
EngineApp.exe --autostart --fastround # 短回合，快速验证回合状态机
EngineApp.exe --autostart --mode=2    # 0=死斗 1=歼灭 2=爆破 3=人质
```

## LLM BOT 配置

主教练战术库按地图分文件加载：`assets/config/coach/_common.txt` 为所有地图共用的总规则，
`assets/config/coach/<playbookId>.txt` 为单图专属的区域别名与 T/CT/经济模板。
`MapCatalog` 的 `playbook` 字段可覆盖文件名，留空时使用地图 `id`；缺地图文件时只加载通用规则并在日志提示。
格式与新增地图步骤见 `assets/config/coach/README.md`，来源见 `assets/config/coach/SOURCES.md`。
改完手册可运行 `python tools/check_coach_playbooks.py` 预检区域名（不启动游戏）。

配置在 `assets/config/llm.ini`：

```ini
[server]
url=http://127.0.0.1:9931

[launcher]
auto_launch=1          ; 自动拉起 llama-server
exe=llm_bot\llama.cpp\llama-server.exe
model=llm_bot\models\qwen2.5-7b-instruct-q4_k_m.gguf
ngl=99
startup_wait=20
kill_on_exit=1         ; 退出时关闭本程序拉起的 server 以释放显存
```

- 模型与二进制体积大，不入 Git；运行 `.\model_setup.ps1` 自动下载。
- 退出时只关闭**本程序拉起**的 server（通过 `llm_server.pid` 记录，跨会话可回收）；
  外部手动启动的服务不会被误杀。

## 素材

素材规格完整契约见 [`tools/ASSET_SPEC.md`](tools/ASSET_SPEC.md)（图片尺寸、朝向、
音效清单、地图对象层约定）。

当前仓库内的部分素材是**占位文件**（带文字标签），由脚本生成：

```powershell
python tools/gen_placeholders.py         # 补齐缺失的图片/音效占位
python tools/gen_placeholder_map.py      # 生成爆破/人质占位地图
python tools/split_spawns.py <map.tmj>   # 通用出生点拆成 spawn_t / spawn_ct
python tools/scale_map.py <map.tmj> --div 2   # 地图整体缩小（每条轴 ÷2 = 面积 ÷4）
```

**真实素材到位后，直接覆盖同名同路径文件即可，无需改代码。**
启动日志会汇总缺失项：`[Asset] 贴图缺失 N 项` / `[Asset] 音效缺失 N 项`。

### 地图

| 模式 | 地图 |
|---|---|
| 死斗 | `cs_office.tmj` |
| 团队歼灭 / 爆破 / 人质 | `ancient_ruins.tmj`（5v5 主战图） |
| 爆破（地图选择可选） | `ancient_ruins.tmj` / `dust_2.tmj` / `mirage.tmj` |

爆破模式的地图清单由 `CS2D/MapCatalog.hpp` 定义，新增地图只需在该目录加一条
（`id` / 显示名 / 描述 / TMJ 路径 / 预览图 / 包点数 / 区域数）。

Tiled 导出的 `.tmj`，放在 `assets/cs2d/maps/`。对象层支持两种写法（可混用）：

- **写法 A**：一个 `Entities` 层，对象带 `type` =
  `spawn_t` / `spawn_ct` / `bomb_site` / `hostage` / `buy_zone`
- **写法 B**：每类一个对象层（`spawn_t` / `spawn_ct` / `bomb_site` / `buy_zone` / `hostage`），
  对象 `type` 留空。同名图层可以有多层，会累加。

`Collisions` 层的所有矩形一律视为阻挡。背景图若引用了工程外的路径，引擎会按文件名
到 `assets/cs2d/tilesets/` 下再找一次。详见 [`tools/ASSET_SPEC.md`](tools/ASSET_SPEC.md) §6。

  Core/                     Types、IniFile、PathUtils
