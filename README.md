# PixelEngine — CS2D-like 单机版

C++17 / SDL2 的俯视角 2D 战术射击游戏，玩法对标 Steam 的 **CS2D**。
玩家可选择 T 或 CT 阵营，与 BOT 进行 5v5 对抗。LLM 教练提供战术计划，BOT 行动由本地规则执行。

---

## 当前玩法

| 模式 | 说明 |
|---|---|
| **团队歼灭** | 回合制 T/CT 对抗，歼灭对方全部成员或时间到守方胜 |
| **爆破** | T 在包点下包，C4 40 秒倒计时；CT 需拆包 |
| **死斗** | 自由击杀，阵亡约 3 秒后重生，无回合 |

### 核心系统

- **回合制**。冻结 2 秒、购买准备 6 秒、交战最长 90 秒，决出胜负后展示 4 秒。
  冻结和购买准备阶段允许转向瞄准。已决展示期间可移动、开火和拾取。先到 8 分获胜。

- **经济（照抄 CS2）**：起始 $800、上限 $16000；回合胜利 +$3250；
  失败按连败递增 **$1400 / $1900 / $2400 / $2900 / $3400**（封顶）；
  T 下包成功后 **T 全员 +$300/人**；CT 拆包成功 **拆包者个人 +$300**。
- **击杀奖励（按武器类型，照抄 CS2）**：步枪/手枪/机枪/手雷 **$300**；
  SMG **$600**（P90 特殊 **$300**）；霰弹枪 **$900**；狙击枪 **$100**；
  刀 **$1500**；Zeus **$0**。
- **开局与装备继承**。首回合双方持起始手枪，CT 为 USP-S，T 为 Glock-18。
  存活者下回合继承武器、护甲和投掷物，阵亡者恢复起始装备。双方使用同一套购买规则。

- **阵营隔离（照抄 CS2）**：T 与 CT 的可购武器互不相通——
  T 专属：Glock-18 / Tec-9 / MAC-10 / Galil AR / AK-47 / SG 553 / G3SG1 /
  Sawed-Off / 燃烧瓶；CT 专属：USP-S / P2000 / Five-SeveN / MP9 / FAMAS /
  M4A4 / M4A1-S / AUG / SCAR-20 / MAG-7 / 燃烧弹；
  其余（AWP、Deagle、P250、CZ75、SSG 08、Nova、XM1014、M249、Negev、
  高爆雷、闪光弹、烟雾弹、诱饵弹）双方通用。
- **持械移速**：拿着不同武器移速不同（匕首 1.00 > 手枪 0.92/0.88 > SMG 0.86 >
  霰弹 0.84 > 步枪 0.80 > AWP 0.72）。玩家与 BOT 共用同一套倍率。
- **画面适配**。内部画布高度以 1080 为设计基准，宽度跟随窗口比例，UI 等比缩放。
  渲染缩放提供 100%、75%、50% 三档，控制内部画布精度。

- **显示设置**。17 档窗口分辨率控制窗口大小，超出桌面可用区时自动适配。
  桌面全屏下禁用窗口分辨率选择，通过渲染缩放调清晰度。帧率上限支持整数输入，
  0 表示不限帧，默认 60 FPS。垂直同步可独立开关，默认关闭。
  设置中的操作与显示、视野与开镜、准星、瞄准线、雷达、音频、键位均可分别恢复默认。

- **LLM 教练管线**：固定 system 前缀（角色/词表/区域表）+ 短状态摘要（比分/经济/
  存活/炸弹/已知敌人区域/上条指令/教练笔记），`max_tokens=150`、温度 0.3、
  `cache_prompt`，尝试 `response_format:json_schema`（服务端不支持时自动回退）。
  每回合最多 8 次调用，关键事件 + 8 秒心跳；计划带 `ttl_s`（3~30 秒），
  回包时回合号或炸弹状态变化即丢弃；回合结束追加一次「一句话复盘」进滚动笔记。
- **对局历史**：主菜单「历史记录」查看最近 50 场（时间 / 模式 / 地图 / 比分 /
  胜负 / K-D / 回合数 / 时长），完成一场比赛后自动写入 `cs2d_history.txt`。
- **投掷输入**。按下开火即投掷，出手时播放投掷音效。投掷方向取当前瞄准方向。
- **地图选择**：三种模式共用同一段俯视相机过场：相机从正面沿四分之一圆弧升到
  当前 3D 空间正上方，随后地图卡片以淡入方式叠加在俯视场景上，仍能看到两侧
  T/CT 和地面移动的小鸡。确认后沿用原来的地图放大加载动画。
  爆破模式与团队歼灭可选：古代遗迹、沙漠Ⅱ、荒漠迷城；死斗目前显示其固定地图。
  阵营弹窗支持淡入/淡出，并提供「随机分配」T/CT。新增地图只要在
  `CS2D/MapCatalog.hpp` 里加一条即可。
- **买枪**：**回合开始后 15 秒内**都可按 `B` 打开菜单（覆盖冻结 + 购买 + 交战初期，
  离开窗口自动关闭），需在己方购买区内且余额充足；买完自动装备。
- **准备阶段**：冻结期可以**转向瞄准**，但不能移动、不能开火。
  回合结算展示期可以移动、开火和拾取装备。
- **拆包**：按住 `E` 期间**不能射击**；松开或离开范围，进度**立刻归零**。
- **投掷物**：一局最多带 **4 个**；闪光可带 **2 个**，其它每种只能 1 个；
  每个投掷物**只能用一次**，用掉即从背包移除。按 `4` 在背包内的投掷物之间循环切换。
  **最后一颗投掷物用完后会自动切回切投掷物之前持有的武器槽**，不会空手。
- **烟雾弹**：爆炸后烟雾从中心向外扩散成多层柔和烟团（不是一次性出现的圆盘），
  会遮挡视线与敌人可见性，并在寿命末尾淡出。
- **燃烧弹 / 燃烧瓶**：落地后炸开并留下一片**持续燃烧的火区**（约 7 秒）：
  范围内所有角色每 0.25 秒受 3 点伤害（约 12 HP/s，含投掷者自己）；
  火区有闪烁的火焰、向上飘散的火星动画，并播放点燃音效。
- **诱饵弹**：落地引爆时播放独立的爆炸音效。
- **匕首**：挥砍现在会播放 `melee_knife.wav`（之前枚举未接上导致无声）。
- **武器库**。34 种枪械及电击枪，另有匕首、6 类投掷物和任务物品 C4。
  - **手枪**：Glock-18 / USP-S / P2000 / Dual Berettas / P250 / Five-SeveN /
    Tec-9 / CZ75-Auto / Desert Eagle / R8 Revolver / Zeus x27（1 发无备弹）
  - **冲锋枪**：MAC-10 / MP9 / MP7 / MP5-SD / UMP-45 / P90
  - **步枪**：Galil AR / FAMAS / AK-47 / M4A4 / M4A1-S / SG 553 / AUG
  - **狙击枪**：SSG 08 / AWP / SCAR-20 / G3SG1
  - **霰弹枪**：Nova / XM1014 / Sawed-Off / MAG-7
  - **机枪**：M249 / Negev
  - **投掷物**：高爆雷 / 闪光弹 / 烟雾弹 / 燃烧瓶(T) / 燃烧弹(CT) / 诱饵弹
  - **近战**：匕首。主/副/近战/投掷四个槽位。
- **手雷**。高爆雷半径 220 世界单位，伤害随距离衰减并经过护甲结算。
  闪光弹按距离致盲，烟雾遮挡视线与敌人可见性，高爆和闪光可影响己方与投掷者。

- **投掷物反弹**。投掷物按子步进碰撞，撞墙沿法线反弹并衰减速度。
  落点和反弹产生听觉信息，附近 BOT 可据此决策。

- **换弹**。各武器拥有独立换弹时长和对应过程音，具体数值由 `WeaponDB` 定义。
  换弹从备弹补充弹匣，切枪和中断按各自的装备状态处理。

- **备弹**：每把武器的备弹上限 = **弹匣容量 × 3**（如 AK-47 30 发弹匣 → 90 发备弹），
  **不是无限子弹**。换弹时从备弹扣取，备弹耗尽后无法再换弹（HUD 显示为 `弹匣/备弹`）。
  每个武器槽各自保存自己的弹匣与备弹，切枪不会互相串味。
- **移动散布 / 动态准星**：静止时使用武器基础散布（最准）；Shift 静步约 42% 速度，
  小幅度扩散；普通跑动满速，散布放大到约 5 倍、准星明显张开。
  按下/松开静步时准星用缓动聚合/散开，不会瞬间跳变。
  设置 → 准星里可切换「动态准星（随移动扩散）」或固定准星。
- **掉落**：阵亡时按 主武器 → 副武器（非标配手枪）→ 随机一个投掷物 的顺序
  掉落一件装备；**保留到本回合结束**。空槽位路过会自动拾取（不切换手持武器），
  按 `E` 可主动拾取并替换；按 `G` 丢弃当前武器（近战除外）。
  **掉落会记录丢弃瞬间的弹匣与备弹**，捡起时原样恢复（BOT 打剩一半的枪捡起来就是一半），
  不会凭空变成满弹。
- **弹药耗尽**：BOT 的弹匣与备弹都打光后会切换到仍有弹药的武器，最后退到近战，
  不会站着空放或反复无效换弹。
- **道具伤害**：高爆/闪光对**所有人**生效（含己方与投掷者）；
  投掷物按子步进做碰撞检测，不会穿墙。
- **玩家与 BOT 脚步音**。普通跑动播放脚步音，玩家采用连续循环，BOT 按步伐播放空间音效。
  静步保持安静，停止、阵亡和暂停时结束玩家脚步循环。

- **护甲**。按武器护甲穿透率结算生命伤害，被吸收伤害消耗护甲值，护甲不足时剩余伤害进入生命值。
  护甲耗尽后头盔失效。购买价格为护甲 $650、甲盔 $1000，拆包钳 $400。

- **目标物**。T 携带 C4，在包点按住互动键安装 3 秒。C4 安装后倒计时 40 秒。
  CT 在 52 世界单位内持续互动拆包，普通拆包 10 秒，持钳拆包 4 秒。
  松开或离开范围会清空个人拆包进度。多个角色各自累计拆包进度。
  掉落与已安装 C4 使用实体素材绘制，雷达提供相应任务信息。

- **视野与镜头**。基础视野以朝向为中心，采用 120° 扇形及柔和边缘，墙体和烟雾遮挡敌人。
  玩家可视范围随视口延伸，BOT 感知范围由难度与调参决定。
  远距离瞄准使用三个镜头距离档，收放采用平滑过渡，最远档会收窄扇形视野。
  支持开镜的武器通过右键循环关闭、1.5×、2×，镜圈内独立放大，镜外保留主场景。
  开镜移速乘以 0.6，开镜灵敏度和十字线外观可在设置调整。

- **致盲**：闪光弹生效期间**完全丧失视野**（整屏不透明，最后 0.4s 淡出）。
  BOT 同样会失明——看不到敌人，也无法向队友上报情报。
- **回合装备继承**：回合结束时**存活**的人保留手上的武器/护甲/投掷物；
  **阵亡**的人下回合回到手枪。对玩家和所有 BOT 一视同仁。
- **BOT 战术协同**。每回合分配突破、支援和断后职责，结合共享情报选择集火目标、掩护、搜点和路线。
  教练计划通过任务目标及节奏影响本地行动层。

- **BOT 视野**。采用朝向扇形、墙体遮挡和烟雾判定，难度影响感知距离、反应和转向。
  行进和驻守期间主动扫描，受击后朝威胁方向警戒。

- **BOT 探点与情报**。发现敌人后向本队上报，情报随时间衰减。
  爆破模式支持 A/B 分兵、CT 分点驻守、情报点清理与投掷物使用。

- **BOT 听声扑人**。下包与拆包过程的听觉半径为 600 世界单位。
  敌方 BOT 可循声接近执行者，开火仍受真实视线约束。

- **脚步听觉**。普通跑动的听觉半径为 260 世界单位，静步降低移速并隐藏脚步信息。
  听觉信息先由具体 BOT 接收，视野发现的敌人情报再按队伍共享。

- **声音传播与听觉**。枪声、换弹、投掷、反弹、爆炸、脚步及 C4 过程分别产生带位置的听觉事件。
  BOT 的事件感知半径集中在 `Tuning.hpp` 与 `SoundEvents.hpp`，听觉事件按阵营、类型和时效处理。
  玩家音频与 BOT 听觉事件分别根据各自传播参数计算。

- **BOT 经济与撤退**：BOT 与玩家共用一套经济（回合奖金 + 击杀奖励），
  每回合购买会先等教练的 save/eco 决策；教练选 save 时全队不采购，余额留到下一回合。
  买/不买按**买枪前经济快照**判断，不会因为刚花完钱就被误判成穷局。
  每回合按余额买护甲（$650/$1000）和武器（AWP / AK-M4 / Galil / SMG / 霰弹）。
  血量 ≤30 时会跑向掩体（要求该点看不见威胁）并边走边换弹。
- **空间音效**。声像取声源相对当前听者的世界位置。普通空间音效随距离衰减，200 世界单位处归零。
  BOT 拆包过程音在 52 单位内全音量，随后衰减至 600 单位处归零，随听者移动持续更新。
  观战跟随者、自由相机和 C4 相机使用对应听者位置。枪声按武器区分，过程音使用独立保留通道。

- **比赛结束**。任一队先到 8 分后进入结算页，由玩家选择返回主菜单或再来一局。
  最后播报至少展示 1.2 秒，死亡定格完成后切换结算。死斗采用持续交战和自动重生。

- **打击反馈**：开枪有枪口火焰；命中敌人时准星出现 X；被击中时屏幕四周泛红。
- **HUD**。血量、护甲、甲盔和装备状态结合实际素材显示。准星和瞄准线支持颜色、连续粗细、透明度等设置。
  阵亡后收起本人瞄准元素，死亡卡显示击杀者和武器。

- **主菜单实时 3D**：独立隐藏 OpenGL 上下文渲染 glTF 角色与三只小鸡（CPU 骨骼蒙皮），
  回读为 SDL 纹理后作为主菜单背景；角色待机、小鸡在全场随机漫游并转向，
  脚底自动贴地并带接地阴影。鼠标悬停时探照灯平滑追踪并高亮，点击后聚焦模型。
- **主菜单自定义**：聚焦 T / CT 后可调 **武器 / 颜色 / 姿势 / 配饰** 四类，
  小鸡可调 **羽色 / 姿势 / 配饰** 三类（右侧轮盘，选中项高亮）：
  - 武器：直接切换角色模型自带的 6 把武器节点（AK-47 / 冲锋枪 / 狙击枪 / 霰弹枪 / 手枪 / 匕首），
    武器保持自己的木/金属色，不随服装调色板变色；
  - 颜色：T/CT 有 8 套**材质槽**配色（上衣 / 裤子 / 靴子 / 装具分别换色，皮肤不变），
    小鸡有 7 种羽色（整体覆盖）；
  - 姿势：人物采用待机 / 下蹲 / 叉腰 / 抱拳，小鸡采用散步 / 待机 / 张望 / 休息；
  - 配饰：鸭舌帽 / 墨镜 / 背包（T/CT），小帽子 / 墨镜（小鸡），配件节点随当前菜单 GLB 导出，按骨骼和挂点显示。
    可编辑源文件与导出入口位于 `tools/menu-models/`。
  自定义结果写入 `cs2d_save.ini` 的 `[menu]` 段，重启后保留。
  模型授权见 `assets/models/CREDITS.md`。
- **页面转场**：所有菜单/设置/历史/暂停页统一使用黑场软切：smoothstep 淡出到
  纯黑并保持一小段后再切页，避免新页面提前露出；时长约 0.34s，转场期间锁定输入。
- **重新开始**：回到游戏内选阵营弹窗；选完后保留当前地图，清空比分与回合计数器并重建首回合。
- **开局加载**：从地图选择页记录的卡片位置放大所选地图预览到全屏，压黑后
  等待 LLM server 就绪（首次可能拉起模型），再淡入对局；加载期间显示进度提示。
  进入游戏后弹出阵营选择，选完重建首回合（不重新加载地图）。
- **BOT 昵称与观战 HUD**。玩家阵亡后定格死亡世界画面 1.8 秒，同时显示击杀者与武器。
  团队模式随后观战存活队友，并显示其生命、护甲和装备。跟随目标阵亡后自动选择下一名队友。
  炸弹已安装且己方全灭时自动切换 C4 上方，展示炸弹和拆包进度。
  死斗定格结束后等待约 3 秒重生时限到达。

- **雷达**：用**地图背景图缩放烘焙**成底图（无背景时用碰撞网格烘一层），
  支持设置里的 居中/旋转/缩放/透明度/尺寸。
- **LLM 教练（唯一的 LLM 消费者）**：本地 `llama-server` 只产出**战术计划**
  （意图 / 目标点位 / tempo / 五个角色槽位），决策上下文包含阵营、回合阶段、比分、金钱、
  任务目标。**LLM 不驱动 BOT 的任何具体行动**——移动、瞄准、射击节奏全部由决策树决定，
  教练计划只通过「去哪、什么节奏」间接影响它们。LLM 不可用时自动回退规则教练。
  计划下发前会做防单点/防重复整形：`default` 全堆一侧会改 A/B 分兵，CT 无情报的
  `stack_*` 会改默认分兵；T 连续压同一侧会强制分兵，避免每回合都撞同一包点。
- **T 下包优先级**：C4 携带者强制跟随主攻侧；进包点后无可见敌人就停下推进下包。
  T 未下包时执行计划有 18 秒锁定，`rush/split/stack/fake` 不会被转点覆盖；
  只有 `default` 在 12 秒后才评估转点，且有人进包点 / 携带者接近包点时禁止转点。
- **CT 拆包决策**：拆包不是贴到炸弹就锁死。拆包手只在「没有可见敌人、最近没挨打」
  时尝试；包点附近还有 T 情报时，其他 CT 去清情报点/在炸弹外围架枪，
  不会全员堆在炸弹上等到最后 6 秒。一旦挨打或看到敌人立即放弃拆包反击，
  并有 2 秒冷却。炸弹最后 6 秒进入强制拆包窗口。
- **BOT 行动层**：纯决策树。每帧推导姿态（强攻/固守/撤退/借掩体）与射击纪律
  （连发/点射/停火），移动一律走 A* 寻路 + 碰撞检测，不存在绕过地图的脚本位移。

## 构建与运行

前置：CMake 3.16+、MinGW-w64（x86_64 UCRT）。SDL2 / SDL2_mixer / SDL2_image
通过 FetchContent 自动下载并校验 SHA-256。

```powershell
cmake --preset mingw-debug
cmake --build build
.\build\EngineApp.exe
```

### 版本与渠道

构建时会写入版本号、渠道和 commit SHA（显示在窗口标题与启动日志 `[Build] ...` 里）：

```powershell
# 玩家版
cmake -S PixelEngine -B build-release -DCMAKE_BUILD_TYPE=Release `
      "-DPE_VERSION=0.3.0" "-DPE_CHANNEL=release"
# 开发版（带回放工具与 --killplayer/--record 等调试参数）
cmake -S PixelEngine -B build-dev -DCMAKE_BUILD_TYPE=Release `
      "-DPE_VERSION=0.3.0" "-DPE_CHANNEL=dev" -DBUILD_DEV_REPLAY_TOOLS=ON
```

- 渠道只影响：标题标识、**存档文件名**（release `cs2d_save.ini`；dev/beta 加
  `_dev` / `_beta` 后缀）、以及是否编入 dev 专用命令行参数。不改变玩法逻辑。
- 打可分发包：`powershell -ExecutionPolicy Bypass -File tools\package.ps1 -Version 0.3.0`
- 发布步骤见 [docs/release-checklist.md](docs/release-checklist.md)。

### macOS 上构建（给 Mac 协作同学）

项目已经用 CMake + SDL2 FetchContent，macOS 上不需要改代码路径或手装 SDL，
只需 Xcode 命令行工具和 CMake：

```bash
xcode-select --install          # 若未安装
brew install cmake              # 或从 cmake.org 下载

git clone https://github.com/sin-X07/PixelEngine.git
cd PixelEngine
cmake -S PixelEngine -B build-macos -DCMAKE_BUILD_TYPE=Release
cmake --build build-macos --parallel
./build-macos/EngineApp
```

说明：
- SDL2 / SDL2_mixer / SDL2_image 首次 configure 时自动下载（需要网络），之后离线可用；
- 构建后会自动把仓库根的 `assets/` 复制到可执行文件旁；
- 中文界面自动使用 macOS 自带 PingFang / 冬青黑体，无需安装字体；
- macOS 上 LLM 教练走桩实现（`LLMBotController_stub.cpp`），自动回退规则引擎；
  其余玩法、渲染、音频与 Windows 一致；
- 键盘布局切换是 Win32 专属功能，macOS 上为空操作，不影响操作。

### 多人协作（Windows + macOS）

1. **加协作者**：GitHub 仓库 → Settings → Collaborators → Add people，
   对方接受邀请后即可直接 push / 开 PR。
2. **分支约定**：`main` 作为稳定线；每个人在自己的 `feature/xxx` 分支开发，
   完成后开 Pull Request 合并回 `main`（仓库已用过 PR #4 的流程）。
3. **同步习惯**：开始改之前先 `git pull --rebase origin main`；
   提交后尽快 `git push`，避免本地 main 和远端分叉。
4. **不要提交构建目录**：`build-*/` 已在 `.gitignore` 中；
   Windows 用 `build-release`，macOS 用 `build-macos`，互不干扰。
5. **换行统一**：仓库根的 `.gitattributes` 已声明文本 LF、素材二进制，
   Windows/macOS 交叉提交不会产生整文件换行 diff。
6. **素材**：`assets/` 是跨平台共用的，路径全部用 `/`，不要写盘符；
   大于约 50MB 的模型/视频不要进仓库（`llm_bot/models` 已忽略）。

## LLM BOT 配置

主教练战术库按地图分文件加载：`assets/config/coach/_common.txt` 为所有地图共用的总规则，
`assets/config/coach/<playbookId>.txt` 为单图专属的区域别名与 T/CT/经济模板。
`MapCatalog` 的 `playbook` 字段可覆盖文件名，留空时使用地图 `id`；缺地图文件时只加载通用规则并在日志提示。
格式与新增地图步骤见 `assets/config/coach/README.md`，来源见 `assets/config/coach/SOURCES.md`。
改完手册可运行 `python tools/check_coach_playbooks.py` 预检区域名（不启动游戏）。

配置在 `assets/config/llm.ini`：

```ini
[server]
url=http://127.0.0.1:9931

[launcher]
auto_launch=1          ; 自动拉起 llama-server
exe=llm_bot\llama.cpp\llama-server.exe
model=llm_bot\models\qwen2.5-7b-instruct-q4_k_m.gguf
ngl=99
startup_wait=20
kill_on_exit=1         ; 退出时关闭本程序拉起的 server 以释放显存
```

- 模型与二进制体积大，不入 Git；运行 `.\model_setup.ps1` 自动下载。
- 退出时只关闭**本程序拉起**的 server（通过 `llm_server.pid` 记录，跨会话可回收）；
  外部手动启动的服务不会被误杀。

## 素材

素材规格完整契约见 [`tools/ASSET_SPEC.md`](tools/ASSET_SPEC.md)（图片尺寸、朝向、
音效清单与命名约定、地图对象层约定）。音效命名统一为 `<分组>_<对象>.<ext>`
（`fire_*` / `reload_*` / `throw_*` / `fx_*` / `bomb_*` / `round_*` / `sfx_*` …），
枪声素材的来源与授权见 [`assets/audio/CREDITS.md`](assets/audio/CREDITS.md)。

当前仓库内的部分素材是**占位文件**（带文字标签），由脚本生成：

```powershell
python tools/gen_placeholders.py         # 补齐缺失的图片/音效占位
python tools/gen_placeholder_map.py      # 生成爆破占位地图
python tools/split_spawns.py <map.tmj>   # 通用出生点拆成 spawn_t / spawn_ct
python tools/scale_map.py <map.tmj> --div 2   # 地图整体缩小（每条轴 ÷2 = 面积 ÷4）
```

**真实素材到位后，直接覆盖同名同路径文件即可，无需改代码。**
启动日志会汇总缺失项：`[Asset] 贴图缺失 N 项` / `[Asset] 音效缺失 N 项`。

### 地图

| 模式 | 地图 |
|---|---|
| 死斗 | `office.tmj` |
| 团队歼灭 / 爆破 | `ancient_ruins.tmj`（5v5 主战图） |
| 爆破（地图选择可选） | `ancient_ruins.tmj` / `dust_2.tmj` / `mirage.tmj` |

爆破模式的地图清单由 `CS2D/MapCatalog.hpp` 定义，新增地图只需在该目录加一条
（`id` / 显示名 / 描述 / TMJ 路径 / 预览图 / 包点数 / 区域数）。

Tiled 导出的 `.tmj`，放在 `assets/cs2d/maps/`。对象层支持两种写法（可混用）：

- **写法 A**：一个 `Entities` 层，对象带 `type` =
  `spawn_t` / `spawn_ct` / `bomb_site` / `buy_zone`
- **写法 B**：每类一个对象层（`spawn_t` / `spawn_ct` / `bomb_site` / `buy_zone`），
  对象 `type` 留空。同名图层可以有多层，会累加。

`Collisions` 层的所有矩形一律视为阻挡。背景图若引用了工程外的路径，引擎会按文件名
到 `assets/cs2d/tilesets/` 下再找一次。详见 [`tools/ASSET_SPEC.md`](tools/ASSET_SPEC.md) §6。
